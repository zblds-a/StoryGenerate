修复为最后一幕可使用整集真实剩余硬预算，保留整集上限；通过显式 retry 仅重做未成功第三幕，保留前两幕。恢复阶段 67.750 秒、增加 2 次调用，最终累计 11 次。恢复阶段耗时不是首次整集生成耗时，重复报告的累计调用和 token 不相加。两次运行之间还包含排查时间，不作为模型耗时。

随后通过业务 HTTP 回放验证真实交付：鉴权、外部 owner 拒绝、快照、导出完全相同、事件不缺不重、游标越界、旧确认冲突、读取不增加模型调用，全部通过。

## 保护范围
